about me

hello, i'm thebadlorax! i made this website (and still make it), and i guess i'm here to talk about myself and this place. this website is hosted by myself, and made with very few libraries, to get my to learn the most (ofc limited ai usage as well)

i've been making stuff for a long time (since middle school), but finaly i felt the urge to make somewhere i could put all of it. i was also enticed with learning web dev, because i used to think it was super easy, like im so cool with my elite python skills they don't know anything. (i was definitely deluded)

in a way, this is my portfolio, as everything before this website is so much worse than anything on it. making this place has let me grow an insane amount, and even if i look back on my old code (like the chat, one of the first things to be made) and want to claw my eyes out, i'm still insanely proud of this. i'm going to continue updating thebadlorax.dev for a long time, and probably get around to rewriting the old sections. feel free to explore! there's no sitemap, and there are a bunch of little hidden things (including a whole puzzle/arg thing). have fun!
